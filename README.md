# Movie Recommendation System

An AI-based Movie Recommendation System developed during my Artificial Intelligence internship using Python and Streamlit.

## Features
- Content-based movie recommendations
- Streamlit web application
- Movie similarity recommendation engine
- Dataset processing and filtering

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

## Project Files
- `app.py` → Streamlit application
- `Movie_Recommendation_System.ipynb` → Model development notebook
- `movies.pkl` → Processed movie dataset
- `Movie_Recommendation_Report.pdf` → Project report

## Note
Some large datasets and similarity files were excluded due to GitHub upload size limitations.
